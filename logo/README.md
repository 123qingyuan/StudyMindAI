# StudyMind · Logo 设计方案

## 设计理念

> **「书籍之上，燃起灵感之火」**

标志由两个核心意象组成：

- **火花（AI 星光）**：四角凹星代表「思维 / 灵感 / AI」——既是经典的人工智能「闪光」符号，也像一颗被点亮的心智。
- **打开的书籍**：代表「学习 / 知识」——摊开的书页承载内容，是学习空间的根基。

两者上下组合，表达 **Study + Mind** 的品牌内核：*在知识的书籍上，点燃思维的火花*。

- 火花正中的 **青绿色圆点** 是「灵感的火种 / 神经节点」，是整枚标志的记忆点，也呼应 AI 的「智能核心」。
- 书页上的 **浅色纹理线** 暗示层层叠叠的知识页面。

## 配色

| 用途 | 色值 | 名称 |
| --- | --- | --- |
| 火花渐变起 | `#8B5CF6` | 紫罗兰 Violet |
| 火花渐变止 | `#4F46E5` | 靛蓝 Indigo |
| 书籍渐变起 | `#6366F1` | 亮靛蓝 |
| 书籍渐变止 | `#4338CA` | 深靛蓝 |
| 灵感火种 | `#2DD4BF` | 青绿 Teal |
| 文字主色 | `#1E1B4B` | 墨靛 Ink |
| 副标灰 | `#6B7280` | 中性灰 |
| 单色版 | `#0F172A` | 近黑 Slate-900 |

**情绪定位**：靛蓝/紫罗兰传达「专注、智慧、可信」，青绿点缀传达「成长、活力、洞察」。

## 字体

- 文字标志使用无衬线几何字体：`Segoe UI / PingFang SC / Microsoft YaHei / Noto Sans SC`（系统字体，跨平台可用，无需额外嵌入）。
- 字重 800，「Study」用墨靛色、「Mind」用紫→靛渐变，弱化分界、强化一体感。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `studymind-mark.svg` | 主体标志（彩色、透明底，网站/文档默认使用） |
| `studymind-mark-mono.svg` | 单色标志（打印、水印、favicon、深色/浅色底通用） |
| `studymind-logo-horizontal.svg` | 横版完整标志（图标 + 文字 + 副标语，导航栏/页脚/名片） |
| `studymind-app-icon.svg` | 应用图标（圆角方形，桌面/移动端启动图标） |

## 使用建议

- **最小尺寸**：标志建议不小于 24px；小尺寸（如 16px favicon）请使用 `studymind-mark-mono.svg`。
- **留白**：标志四周保留至少标志高度 25% 的安全留白。
- **背景**：彩色标志适合浅色/白色背景；深色背景请使用单色版或应用图标版。
- **文件格式**：均为矢量 SVG，可无损缩放到任意尺寸；如需 PNG/ICO，可基于 SVG 导出（建议 16/32/48/64/128/256/512px）。
